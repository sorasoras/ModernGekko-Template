## Defects

- **Slow/deep audio + ~22 fps in gameplay** under static-recomp + `--allow-interpreter`:
  interpreter fallback drags the emulated clock below real time, which slows the audio with it.
  **JIT mode (`MODERNGEKKO_STATICRECOMP=0`) fixes the audio** (user-confirmed).
- `present_count` advances ~64-67/s regardless of mode, so it is not a usable fps signal - it
  counts queued VI presents. A swapchain-sampling counter is needed before performance work.
- `AudioSystem::SetDmaSink` has no caller in the runner (only a unit test), and
  `AiCyclesPerSample = 10116` implies ~72 kHz production against a 48 kHz-class sink. Audio is
  audible through the vendored Dolphin mixer path; the AI constant deserves a pass once fps is
  measured properly.

## Running it

    run_sr.cmd     REM static recomp + interpreter fallback (audio slow in gameplay)
    run_jit.cmd    REM JIT mode - audio correct, use this one

Input during a session goes through the automation dir:

    printf 'command=pad_frames\nport=0\nframes=15\na=1\nwii_a=1\n' > mg_auto/commands/a.txt
    printf 'command=screenshot\npath=shot.png\n' > mg_auto/commands/s.txt
    printf 'command=save_state\npath=check.sav\n' > mg_auto/commands/sv.txt

`docs/shots/` keeps the two milestone frames (title screen, intro cinematic).
